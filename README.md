# scribd_web_scrap
Scribd sitesinden giriş pdf indirmek için gereken giriş iznine gerek kalmadan, pdf formatında veri çeken python kodu.

### Çalışma Şekli

Colab üzerinden çalışmaktadır, gerekli paketler ilk hücredeki komut ile kurulur.

Daha sonra ikinci hücredeki  python kodu ile doğru dosya mı kontrol edilir.

Son olarak da üçüncü hücredeki komut ile ana python kodu çalışarak, 276 sayfa için ortalama 15 dk olarak hesaplanmıştır,
veriler önce ekran görüntüsü olarak toplanır sonra da tek bir pdf dosyasında birleştirilir.

Sonda yer alan komut ile colab ın dizininden bilgisayarınıza çekilebilir.
